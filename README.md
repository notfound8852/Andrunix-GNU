# Andrunix-GNU
A true GNU/Linux integration for Android BELOW Android 10 (Android 10+ have not been tested. and ARE much different from older models)—no chroot, no PRoot, no Chroot or any containerization. Just pure, native execution with Glibc.
**Main Guide: [here](https://github.com/notfound8852/Andronux-GNU/blob/main/Andrunix/README.md)**
